# DAI VIET - Prehistoric Signature System

## Intent

DAI VIET should feel like a living island community, not a game-service dashboard. The system combines dark natural space, rose-smoke signal color, readable Vietnamese type, and a proprietary claw-island mark.

## Signature Mark

The `PrehistoricMark` is an original project-owned vector mark: three downward claw strokes curve into an island/horizon contour. It is not a mascot, a game asset, or a derivative of another server identity. It is used as a focal visual, divider, favicon-scale signature, and motion anchor. The existing `DV` navbar mark remains the default logo.

## Color Roles

| Role         | Value     | Use                                            |
| ------------ | --------- | ---------------------------------------------- |
| Rose signal  | `#ffbdbd` | Calls to action, active state, mark highlights |
| Rose smoke   | `#c98490` | Quiet annotations and subtle separators        |
| Coral ember  | `#ef8f84` | Sparse warmth in highlights                    |
| Forest black | `#09100d` | Primary environmental ground                   |
| Charcoal     | `#101512` | Reading surfaces and footer                    |
| Warm gray    | `#ded8d0` | Main type on dark backgrounds                  |
| Moss signal  | `#b8dcae` | Verified live data only                        |

Rose is an event color, not an all-over tint. Green is reserved for data that is actually verified.

## Typography

- **Display:** a heavy, open sans-serif treatment with generous line-height and short two-to-four-word phrases.
- **Body:** the system UI sans serif for Vietnamese diacritics and sustained readability.
- **Scale:** desktop display 64-82 px; section headings 38-52 px; body 15-17 px. Mobile display 42-50 px; headings 29-34 px; body 14-16 px.
- **Rules:** no all-caps paragraphs, no condensed type, no long hero title wraps, and no letter-spacing tricks used to fake a logo.

## Composition

- Favor one large visual field and a single focal mark over a cluster of outlined cards.
- Use wide, breathing section bands and soft topographic/wave transitions.
- Present lists as field rolls, trails, or editorial indexes; do not turn every concept into a card.
- Use an irregular organic mask or silhouette only where it identifies a meaningful area. Never add diamonds, grids, or borders merely as decoration.

## Motion And Interaction

- One entrance reveal per major section, driven by CSS only.
- The mark may drift a few pixels and reveal with opacity; motion stops for `prefers-reduced-motion`.
- Hover effects illuminate a real route or expose a small text detail. They never imply unavailable gameplay.
- Buttons only exist for working navigation. Unavailable destinations are concise text states.

## Accessibility And Data

- Maintain semantic section headings, visible keyboard focus, sufficient contrast, touch targets, and an orderly mobile reading sequence.
- Public community output is limited to display name, species, and online status. Server values are shown only when provided by the existing safe API layer.
- The product layers never state that a missing route, map, shop, or garage is available.

## Anti-Patterns

- Repeated bento cards and utility tiles.
- Decorative grids, diamonds, status pills, and outlined rectangles with no narrative role.
- Generic forest photography as the only identity signal.
- Fake community activity, simulated maps, fictional capacity, fake download/authentication actions, and hidden personal data.
